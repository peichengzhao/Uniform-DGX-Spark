            网络术语说明
            

              
CX-7 / ConnectX-7
NVIDIA 高速网卡，本机链路最高协商为 200 Gb/s。

              
RDMA
Remote Direct Memory Access，远程直接内存访问，可减少 CPU 参与和数据复制。

              
RoCE
RDMA over Converged Ethernet，在以太网上承载 RDMA；当前设备名通常以 roce 开头。

              
MTU
Maximum Transmission Unit，单个网络包的最大长度；9000 表示启用了 Jumbo Frame（巨型帧）。

              
Gb/s
Gigabits per second，链路理论速率；200 Gb/s 不等于应用一定能达到 200 Gb/s。

              
RX / TX
Receive / Transmit，当前采样周期内的接收与发送速率。

              
错误 / 重传
驱动启动以来的累计计数；单个非零值不代表当前仍有故障，应观察是否持续增长。

              
GPU 核心利用率
GPU 计算单元在采样周期内处于忙碌状态的比例，不代表显存容量占用。

              
显存带宽利用率
GPU 内存控制器的忙碌比例，不是已使用显存容量百分比。

              
统一内存
DGX Spark 的 CPU 与 GPU 共享系统内存。页面按系统统计显示整个共享池的已用量、总量、占比和可用量，不等同于单个模型的 GPU 分配。

              
容器内存
Docker cgroup 统计的容器内存使用量，不等同于该容器独占的 GPU 显存。

Spark Arena 对标评测
使用 llama-benchy 0.4.0 按 Spark Arena 口径测试本地 OpenAI 兼容服务，并与榜单结果计算差距。

          

            评测指标如何理解
            

              
TTFT P50 / P99
从发出请求到首个 token 的中位数和尾延迟，包含排队与 Prefill；交互体验首先看它。

              
TPOT P50 / P99
首 token 之后每生成一个 token 的时间。当前只在单并发时从每轮 Decode 吞吐可靠换算。

              
Prefill 吞吐
处理输入 Prompt 的 token/s，受输入长度、Prefix Cache 和批处理影响。

              
Decode / Output 吞吐
生成输出 token 的持续吞吐。并发时是服务聚合吞吐，不等于单用户速度。

              
峰值 Decode
短时间窗口内的最高生成速率，适合诊断突发能力，不应代替稳定 Decode 成绩。

              
均值 ± 标准差
多轮结果平均值及离散程度；标准差越小，结果通常越稳定，它不是 P99 或误差上限。

              
投机接受率
评测期间 accepted draft tokens ÷ proposed draft tokens；越高不必然越快，还需考虑 draft 开销。
