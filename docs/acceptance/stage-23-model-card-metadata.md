# 阶段 23：模型卡片基础信息

模型卡片新增模型大小、量化/精度、模型结构和参数量。Hugging Face 查询会直接请求 `config`
和 `safetensors` 元数据；ModelScope 使用仓库大小和 `model_type` 标签。跨站条目在后端互补缺失
字段，但页面不展示来源合并信息。

模型大小优先采用站点提供的真实仓库字节数。只有参数类型与数量可用时才估算权重大小，并在
页面显示“约”；无法可靠得到的数据统一显示“未知”或“未标注”。

2. 搜索 `Qwen/Qwen2.5-7B-Instruct`，卡片应显示约 14 GiB、BF16、
   `Qwen2ForCausalLM` 和约 7.62B 参数。
3. 搜索名称带 `AWQ`、`GPTQ`、`GGUF`、`FP8` 或 `NVFP4` 的模型，量化/精度字段应显示对应格式。
4. 检查 ModelScope-only 模型：如果接口没有参数量或架构，卡片应显示“未知”，页面仍应正常
   排版，不能根据名称虚构参数量。
5. 切换发布时间、下载量等排序，新增基础信息应保留且部署按钮仍可点击。

通过标准：四项基础信息都出现在每张卡片；已知数据格式正确，估算值带“约”，缺失值有明确
占位，长架构名称不破坏卡片布局。
