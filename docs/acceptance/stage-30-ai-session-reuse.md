# 阶段 30：同模型 AI 部署会话复用

自动测试：

```bash
./scripts/accept-stage-30.sh
```

人工测试：

1. 在“模型目录”或“本地模型”中，找到一个以前执行过“AI 一键部署”的模型。
2. 再次点击该模型的“AI 一键部署”，确认页面立即显示“正在读取历史会话”，随后列出该模型的历史会话，而不是直接创建新会话。
3. 检查历史项包含会话名称、AI 工具、AI 模型、状态和最近更新时间，并且不混入其他模型的会话。
4. 对仍为 `running` 的会话点击“打开并继续”，确认直接进入原终端，原终端输出和部署结果仍然存在，且不会新增会话。
5. 对 `stopped`、`exited`、`failed`、`interrupted` 或已存档会话点击“恢复并继续”，确认页面立即显示恢复等待状态，随后在同一个终端中自动发送“继续执行上次部署”。原终端记录应保留并继续追加。
6. 再次点击该模型的“AI 一键部署”，选择“新建 AI 会话”，确认仍可进入完整部署配置并创建独立会话。
7. 对从未部署过的模型点击“AI 一键部署”，确认不显示空选择页，直接进入新会话配置。

通过标准：同一模型可以明确选择复用历史会话或新建会话；复用不会复制会话，运行中会话直接打开，已结束会话通过 Codex/Claude Code 原生恢复能力保留上下文继续运行。
