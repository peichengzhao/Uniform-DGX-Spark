# 阶段 26：AI 会话身份与生命周期管理

自动测试：

```bash
./scripts/accept-stage-26.sh
```

人工测试：

1. 打开“AI 调试”，点击“新建 AI 会话”。
2. 填写会话名称，选择或输入 AI 模型，并选择 Codex 思考强度。
3. 启动后确认会话列表和终端标题显示会话名称、AI 模型与思考强度。
4. 从任意模型卡片点击“AI 一键部署”，确认会话名称默认等于模型短名，列表显示完整目标模型 ID。
5. 选择 Claude Code，确认思考强度被禁用；AI 模型仍可指定。
6. 停止或等待会话结束后点击“存档”，确认它从默认列表隐藏；勾选“显示已存档”，确认可见并可恢复。
7. 对非运行会话点击“删除”并确认，确认会话和终端记录消失；关联部署、外部模型和容器不受影响。
8. 对运行中的会话点击“删除”，确认页面明确警告会停止 AI 进程；确认后会话被删除，其他会话和已启动的模型容器不受影响。

通过标准：API 持久化四项信息，Codex 命令收到 `--model` 和会话级
`model_reasoning_effort`，旧数据库能够无损迁移，旧会话仍可读取并从部署上下文恢复目标模型；
存档可恢复，删除仅清理指定会话；运行会话需要二次确认并会先停止对应 AI 进程。

该测试使用临时数据库和 `/bin/echo` 模拟 CLI，不启动模型容器，不产生需清理的 Docker 资源。
