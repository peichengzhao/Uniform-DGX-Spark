# 阶段 40：模型精度评测 Web 工作区

## 阶段边界

将阶段 37～39 的持久化、EvalScope 后台执行与 HTTP API 接入已有 Web 页面。
本阶段不增加新的模型执行协议，不改变生产数据库结构，不进入阶段 41。

实现内容：

- 独立“精度评测”导航；原有性能评测与 Spark Arena 保持独立。
- 运行中托管部署、已验证 AI 部署的目标选择与部署卡片/详情快捷入口。
- 快速、均衡、正式、自定义预设；GSM8K、ARC、C-Eval 子集与每子集样本数配置。
- Few-shot、批大小、超时、随机种子与生成参数配置；修改配置自动标记为自定义。
- 创建、自动刷新任务列表、进度、终态错误、样本统计与归一化指标表。
- 任务详情、脱敏日志、白名单 JSON 工件下载、按原配置重跑、取消与删除。
- 功能关闭提示、请求错误提示、表单校验，以及桌面/390px 手机布局。

## 预设契约

| 预设 | GSM8K main | ARC | C-Eval | 计划样本上限 |
| --- | --- | --- | --- | --- |
| quick-objective-v1 | 20 | 不启用 | 不启用 | 20 |

| formal-objective-v1 | 1000 | Easy、Challenge 各 500 | 10 学科 × 200 | 4000 |
| custom-objective-v1 | 用户配置 | 用户配置 | 用户配置 | 按启用子集计算 |

均衡预设学科：`computer_network`、`operating_system`、`college_programming`、
`advanced_mathematics`、`logic`。

正式预设学科：`computer_network`、`operating_system`、`computer_architecture`、
`college_programming`、`advanced_mathematics`、`probability_and_statistics`、
`high_school_mathematics`、`college_physics`、`logic`、`law`。

固定预设均为 0-shot、batch=1、timeout=300 秒、seed=42、max_tokens=2048、
temperature=0、top_p=1。切换回固定预设会恢复这些参数，不继承此前的自定义生成参数。

样本数是每子集上限，不保证数据集有足够题目。正式预设不是完整官方排行榜评测，
不能与不同提示词、子集或生成参数的结果直接等同。`partial` 表示执行/报告未达到完整成功条件，
不能当作完整成绩。仅 `accuracy:mean` 且值处于 [0,1] 的指标显示为百分比；其他指标保留原始数值。

## 自动验收

在项目目录执行：

```bash
./scripts/accept-stage-40.sh
```

脚本先复验阶段 39（包含阶段 38），随后执行阶段 40 静态、真实浏览器和通用 API 回归，
并检查 JavaScript 语法、全项目 Ruff 与 Python 编译。

依赖现有 `.venv`、Node.js 和 Chromium；脚本优先使用项目已有 ARM64 Node.js。
浏览器默认探测本机 Chromium/Chrome，也可指定：

```bash
UNIFORM_TEST_CHROMIUM=/absolute/path/to/chromium ./scripts/accept-stage-40.sh
```

一键验收强制要求浏览器，未安装时失败而非跳过。常规全量 Pytest 可在无浏览器时跳过浏览器测试，
因此验收还需检查是否有 skip，或使用下面的强制浏览器全量命令：

```bash
PATH="$PWD/.runtime/node-v22.23.3-linux-arm64/bin:$PATH" \
  UNIFORM_REQUIRE_BROWSER=1 .venv/bin/python -m pytest -q
```

覆盖证据：

- 页面标识、四个预设、API/下载接线和静态资源版本一致。
- Chromium 加载真实页面，点击部署入口，验证目标、预设和生成参数恢复。
- 空样本数、非法高级参数、没有启用数据集、非法 C-Eval 学科均阻止有效任务创建。
- 非法高级字段会自动展开所在配置面板；390px 页面无整体横向溢出、底部按钮未被编辑工具条覆盖。
- 真实浏览器 → 本机真实 HTTP API → 临时 SQLite → 后台 manager → 模拟 EvalScope 进程闭环。
- 运行/完成状态、模拟指标、凭据脱敏日志，以及带 API Key 的真实 JSON 文件下载。
- 日志中的 HTML 保持文本，不产生图片节点或执行事件处理器。
- 原配置重跑、取消、终态删除并验证该任务目录清理。
- 功能关闭时显示说明并禁用工作区创建入口；浏览器无未处理运行异常。

自动测试使用假的 Docker 发现/健康结果和模拟 EvalScope 进程，不访问真实模型、下载数据集、
修改生产数据库或重启生产服务。测试中的 `100.00%` 仅为固定模拟报告，不是模型精度成绩。
真实 EvalScope 兼容性证据仍以阶段 36 为准。

## 人工浏览器验收

前提：已有运行中的目标模型；Accuracy 功能已启用，EvalScope command/source 满足阶段 36～39
的固定身份与运行配置。人工真实评测会产生模型请求和独立任务目录，首次使用推荐快速预设。

1. 打开已有服务页面，进入“精度评测”。预期显示目标选择、三组预设说明和任务记录，原有性能页面不变。
2. 选择运行中的模型并点击“配置并开始评测”；也可从部署卡片/详情点击“精度评测”。预期目标正确预填。
3. 分别选择快速、均衡、正式预设。预期启用数据集、子集、样本上限与上表一致；高级生成参数恢复固定值。
4. 修改样本数或高级参数。预期预设变为“自定义”。清空必填数值、令 max_tokens=0、关闭所有数据集，
   或输入不存在的 C-Eval 学科后尝试提交。预期出现浏览器/页面校验或服务端错误，不创建有效任务。
5. 恢复快速预设并开始评测。预期弹窗关闭、出现任务卡片，状态和进度自动更新，活跃任务期间工作区不允许再启动。
6. 打开“详情、日志与工件”。预期运行期持续刷新；凭据不直接显示；失败时能看到明确的错误而非虚假的空列表。
7. 完成后检查状态、样本完成/异常数和指标表。预期数学精度以百分比显示，子集/指标对应报告；
   下载配置或报告 JSON，预期文件可解析且与目标模型、请求参数一致。
8. 选择“按此配置重跑”。预期目标与所有参数恢复；提交后取消，预期任务进入取消状态，模型服务继续运行。
9. 等待取消进程退出，再删除该测试任务并确认。预期记录与对应目录清理；运行中任务不提供直接删除。
10. 将浏览器缩窄到约 390px，再打开配置与详情。预期单列配置、内容可滚动、操作按钮可见且可点击；
    指标表允许容器内滚动，不挤宽整个页面。
11. 在隔离测试实例关闭 Accuracy 后刷新。预期显示管理员关闭提示、禁用工作区入口，不将 403 当作部署失败。

## 通过与失败标准

通过：一键验收、强制浏览器全量回归、Ruff、JS 语法和编译全部通过；人工路径的页面与状态符合预期；
原有部署、性能、鉴权和阶段 37～39 功能无新增回归。

失败：浏览器缺失导致验收跳过、未处理页面异常、鉴权下载失败、配置与提交不一致、日志 HTML 被执行、
手机按钮被遮挡、运行任务不能取消或删除越过任务目录，任何一项都不能视为本阶段通过。

## 临时资源与清理

自动测试为每个用例创建独立临时数据库、任务目录、浏览器 profile、下载和截图，全部位于 Pytest 临时目录；
HTTP 监听只绑定 127.0.0.1 随机端口。浏览器进程、服务器线程、manager 和模拟子进程在测试退出时关闭。
Pytest 会轮换临时目录，但可能保留最近几次的诊断文件；不声称磁盘文件全部立即删除。
如需清理，仅删除本次确认的测试目录；不要删除生产数据目录或整个 `/tmp`。

人工测试产生的任务通过终态“删除记录”清理，会永久删除该任务目录内的缓存、日志和工件。
有保留需求时先下载白名单报告；该操作不删除模型权重或停止模型服务。
