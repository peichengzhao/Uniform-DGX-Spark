# 阶段 28：AI 一键部署即时反馈与防重

自动测试：

```bash
./scripts/accept-stage-28.sh
```

人工测试：

1. 在模型卡片点击“AI 一键部署”，选择一个包含参考教程的任务。
2. 点击“启动 AI 部署”。确认弹窗立即关闭、页面立即跳转到 AI 区域，并显示“正在创建 AI 会话”。
3. 在 Codex 启动前确认会话列表有“正在准备”卡片，终端区域有动画和“请勿重复提交”提示。
4. 快速连续点击提交位置，确认按钮已禁用，不会出现第二个会话。
5. Codex 启动后，确认等待卡片自动替换为真实会话，终端可正常交互。
6. 在浏览器开发者工具中对同一 `client_request_id` 重放创建请求，确认返回同一会话 ID，列表中仍只有一条记录。
7. 断开网络或使 AI CLI 不可用，确认同一等待卡片转为“创建失败”，并提供“返回配置并重试”。

通过标准：用户点击后立即看到进度；前端不能并发重复提交；后端在重放同一请求时仅保留一个 AI 会话和一条创建审计记录。
