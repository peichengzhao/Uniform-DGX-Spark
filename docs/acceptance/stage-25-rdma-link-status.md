# 阶段 25：RDMA 物理链路与网络状态分离

本阶段修正把 RDMA `ACTIVE/LINK_UP` 直接显示为“已连接”的误导。探针现在分别返回物理链路、
可用 IP 配置和对端可达性；页面不再把协商出 200 Gb/s 等同于网络可用。

状态含义：

- `网络已配置`：物理链路建立并具有非 loopback、非 link-local 的 IP；对端仍未主动探测。
- `仅物理链路`：有 carrier 且 RDMA 为 ACTIVE，但没有可用于通信的 IP。
- `链路未建立`：没有完整的物理/RDMA link-up 状态。

## 当前双机人工验收

1. `Ctrl+Shift+R` 刷新 `http://127.0.0.1:18180`，进入“系统监控”，点击“立即刷新”。
2. 本机 `enP2p1s0f0np0` 应显示黄色“仅物理链路”，下方显示“无 IP · 对端未验证”；不能显示
   “已连接”。200 Gb/s 仅表示物理协商速率。
3. 本机 `enp1s0f0np0`（当前 `10.0.22.1`）和远端 `enp1s0f1np1`（当前 `10.0.22.2`）应显示
   绿色“网络已配置”。这仍不等于对端探测成功，所以页面明确注明“对端未验证”。
4. 远端没有 IP 的 `enP2p1s0f1np1` 同样应显示“仅物理链路”。物理断开的端口显示“链路未建立”。
5. 页面顶部汇总应分别统计“物理链路已建立”的端口数和“已配置网络”的端口数。

通过标准：无 IP 端口不会显示为网络连接；有 IP 端口也不会被描述成已经验证对端可达。接口名、
IP 和状态仍来自每次动态采集，不写死当前机器参数。

本阶段只读取网络状态，不修改接口、IP、MTU、路由或远端机器，无需清理资源。
