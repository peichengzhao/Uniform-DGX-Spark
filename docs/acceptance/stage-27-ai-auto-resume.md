# 阶段 27：AI 中断自动续跑

自动测试：

```bash
./scripts/accept-stage-27.sh
```

人工测试：

1. 打开一个正在运行的 AI 会话终端。
2. 点击“自动续跑”，设置最大重试次数、首次等待时间和续跑指令。
3. 点击“启用并重置计数”，确认工具栏显示“自动续跑：监测中 0/N”。
4. 当终端出现限流、响应流中断、连接重置或超时时，确认状态变为“等待重试 X/N”。
5. 等待倒计时后，确认原会话收到“继续执行上次部署”，没有创建新会话。
6. 在“操作审计”中确认有 `auto_resume_scheduled` 和 `auto_resume_sent` 记录。
7. 连续制造中断并达到上限，确认显示“已用完重试”，不再发送指令。
8. 点击“关闭自动续跑”，确认后续中断不再触发。

通过标准：仅在原 AI 会话存活时发送续跑指令，按指数退避且不超过用户设置的次数；停止或删除会话后不会继续发送。
