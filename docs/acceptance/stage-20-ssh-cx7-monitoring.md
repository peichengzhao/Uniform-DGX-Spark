# 阶段 20：动态 SSH 双机与 CX-7 监控

本阶段只增加 SSH 只读监控，不允许平台或 AI 通过该通道修改远端机器、启动容器或执行部署。

## 自动测试

```bash
./scripts/accept-stage-20.sh
```

预期最后显示：

```text
PASS: stage 20 dynamic SSH and CX-7 monitoring passed.
```

自动测试验证节点配置持久化、输入校验、固定只读探针、SSH 公钥模式、严格主机指纹校验、并发
采集、离线降级、实时速率计算，以及动态 hostname、IP、网卡名、RDMA 名称和容器名解析。

## 当前双机人工验收

1. 打开 `http://127.0.0.1:18180`，进入“系统监控”。
2. 在“多机与 CX-7”填写：

   ```text
   节点名称：第二台 DGX Spark
   SSH 主机：10.0.22.2
   SSH 用户：dgx-spark
   SSH 端口：22
   ```

3. 点击“添加节点”，再点击“立即刷新”。预期同时显示本机 `aitopatom-e17c` 和远端实际
   hostname `aitopatom-3bc5`。
4. 检查页面实际探测结果：本机直连地址当前为 `10.0.22.1`，远端当前为 `10.0.22.2`；两端
   对应接口可能不同，页面必须分别显示本机 `enp1s0f0np0` 和远端 `enp1s0f1np1`，不能用
   前端固定名称替代。
5. 两端直连 RDMA 端口应显示 `ACTIVE / LINK_UP`、200 Gb/s、MTU 9000、`mlx5_core`，并每
   5 秒更新收发速率。其他未接线端口也按本机实际状态展示。
6. 容器列表应动态读到本机 `qwen38-flash-next-head` 和远端
   `qwen38-flash-next-worker`；页面不读取或显示容器命令、环境变量和 API Key。
7. 暂停远端 SSH 或断开网络后刷新，远端应变为离线，本机监控仍正常；恢复后应自动回到在线。
8. 点击“移除”只删除本地登记记录，不应停止或修改远端容器。

通过标准：所有名称、IP、接口和容器均来自本次采集；变化后下一次成功采集自动更新。SSH
目标可以配置稳定 hostname，也可以配置当前 IP。若作为连接入口的 IP 本身发生变化，需通过
稳定 DNS/SSH alias 或在页面更新目标；平台不会扫描网段并尝试登录未知机器。

安全说明：平台只使用现有 SSH Key/ssh-agent，不接收或保存密码，并要求目标已经存在于
`known_hosts`。远端探针只返回资源、网络和安全筛选后的容器摘要，不返回容器命令或环境变量。
