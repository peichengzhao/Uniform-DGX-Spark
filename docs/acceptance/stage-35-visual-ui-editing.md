# 阶段 35：右键 AI 可视化 UI 编辑

## 自动验收

```bash
./scripts/accept-stage-35.sh
```

预期结果：UI 编辑存储、隔离直接修改、截图上下文、Git 提交、对话续写、整体撤销和冲突保护测试通过，
Python 与浏览器 JavaScript 静态检查通过。

## 人工验收

1. 启动 `./scripts/run-local.sh` 并打开 <http://127.0.0.1:18180>。
2. 点击右下角“编辑 UI”，确认鼠标经过页面元素时显示绿色选区。
3. 右键一个标题，输入“将这个标题改成更简短的中文”，范围选择“仅当前元素”。
4. 确认页面以对话形式实时显示 AI 说明、命令和测试输出；执行中追加一条要求并确认 AI 继续处理。
5. 确认标题已经改变，当前导航页和滚动位置得到恢复。
6. 点击“撤销上次修改”，填写原因，确认页面整体恢复到本次编辑之前。
7. 点击“截图批注”，在浏览器共享选择器中选择当前标签页；确认弹窗显示完整截图。
8. 在截图中只圈选一个局部区域并填写修改意见，确认预览保留全图且清楚标出局部关注区域。
9. 提交后确认任务正常进入 Codex 对话页。工作区应同时包含原始全图、带标注全图和局部裁剪图，
   `UI_EDIT_CONTEXT.json` 应包含圈选坐标及相关 DOM 路径，但不包含 base64 图片正文。
10. 点击“执行记录”，确认当前及历史修改均独立列出；切换记录时，任务 ID、Codex session、
    CLI 对话时间线和原始脱敏输出随所选记录切换，正在运行的记录会自动刷新。
11. 保持执行记录或其他业务弹窗打开，确认编辑工具栏位于弹窗上方；启用“编辑 UI”后可右键选择
    弹窗内部组件，也可点击“截图批注”捕获并圈选包含该弹窗的页面。

## 通过标准

- 用户不需要进入 AI 终端或手动提供源码文件名。
- AI 在隔离 Git 工作区直接修改前端，可进行多文件重构、创建文件、测试和自主修复。
- 普通校验失败会成为 AI 反馈；最终仍可带警告应用，不会直接否决用户需求。
- 执行期间的源码冲突不会静默覆盖当前页面源码。
- 成功修改和撤销都会自动刷新页面。
- 一次编辑只产生一个用户级 Git 提交，内部尝试不会成为用户回滚点。
- 回滚必须记录原因，后续任务会把历史回滚反馈提供给 AI。
- 对话窗口保留脱敏后的 Codex 操作、测试日志和最终错误，并支持人工干预和停止。
- 截图编辑同时向 Codex 提供全局原图、带局部标注的全图和局部细节，不以裁剪图替代全局上下文。
- 每次用户修改使用独立 Codex session；同一修改内的自动修复和人工干预延续该 session，执行记录
  可以分别查看当前与历史任务的可读对话及原始脱敏输出。
- 页面、抽屉和弹窗中的可见 UI 均可使用组件右键或截图圈选发起修改，模态层不会遮挡编辑入口。
- Codex 不可用或功能被禁用时，入口给出明确错误。

## 已知限制

- 当前编辑范围是内置 Web 前端目录；新增依赖时仍需考虑项目离线运行环境。
- 元素定位优先使用 `data-ui-id`、元素 ID 和 DOM 路径；动态列表内容只作为定位线索，不能
  被硬编码为业务数据。
- 每次只允许一个 UI 修改任务运行。
- 标签页截图依赖浏览器的屏幕共享权限和安全上下文；localhost 可直接使用，远程访问需要 HTTPS。
