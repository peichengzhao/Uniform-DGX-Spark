# 阶段 4 验收：本地 Web UI 与过程可视化

## 已实现

- 浏览器本地控制台，无 Node/Electron 运行依赖。
- 部署表单、基础/高级 vLLM 参数。
- 实时任务卡、百分比、状态、事件时间线和错误信息。
- SSE 实时更新；启用 API Key 时自动切换安全轮询。
- 原始 vLLM 日志、停止/取消/重试操作。
- 模型目录与系统监控页面。
- 页面关闭后任务继续由后台执行。

## 自动验收

```bash
./scripts/accept-stage-4.sh
```

预期：

```text
PASS: stage 4 acceptance checks succeeded.
```

## 人工验收

1. 运行 `./scripts/run-local.sh`。
2. 打开 `http://127.0.0.1:18180`，应直接看到部署中心，而不是 404。
3. 缩放浏览器或用手机宽度检查页面布局。
4. 创建部署后刷新页面，任务必须仍然存在。
5. 部署过程中关闭页面再打开，进度和历史事件必须恢复。
6. 打开任务详情，检查日志是否持续更新且长日志可滚动。
