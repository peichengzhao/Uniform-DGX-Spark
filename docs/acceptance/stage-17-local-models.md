# 阶段 17：可配置本地模型目录

自动测试：

```bash
./scripts/accept-stage-17.sh
```

测试覆盖目录添加与移除、模型元数据解析、量化类型、权重大小、缺失分片检测、只读保证，
以及本地模型 AI 部署的会话级权限。测试使用临时小文件，不读取或修改真实权重。

人工测试：

1. 打开“本地模型”，确认已添加 `/home/zaki/model`。
2. 页面应显示该目录下的三个模型，包含路径、架构、量化格式、权重文件数、大小、配置和
   tokenizer 状态。
3. 点击“刷新模型”，确认页面重新扫描磁盘。
4. 输入另一个绝对目录并点击“添加目录”，确认配置在页面刷新和服务重启后仍保留。
5. 点击目录标签的 `×`，确认它只从页面移除，磁盘目录和权重文件仍然存在。
6. 点击“配置部署”，确认模型 ID 和本地模型目录已自动填入。
7. 点击“AI 一键部署”，确认 AI 目标摘要显示本地绝对路径，且 AI 能读取模型元数据并优先
   参考可选教程选择引擎、镜像和版本。

通过标准：上述三个模型均可见，移除目录不删除文件，本地部署不会重新从模型网站下载权重。
