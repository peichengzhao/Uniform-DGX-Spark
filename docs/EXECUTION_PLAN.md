## 阶段闸门规则

1. 每次只执行一个阶段。
2. 当前阶段必须完成实现、自测和验收报告。
3. 报告必须列出测试证据、失败项、已知限制和残留资源。
4. 报告提交后停止，不提前实现下一阶段。
5. 只有收到用户明确的“验收通过，继续”后，才进入下一阶段。

## 每阶段验收材料

每一阶段结束时必须向用户提供：

- 一键自动测试命令和测试脚本。
- 必须人工观察或操作的测试步骤。
- 每项测试的预期结果。
- 明确的通过与失败标准。
- 测试产生的资源及清理方法。
- 已知限制和未覆盖场景。

自动测试由开发侧先完整执行一次，再交给用户复验。涉及 Web UI 的阶段还必须提供逐步的浏览器验收路径，不能只提供后端接口测试。
