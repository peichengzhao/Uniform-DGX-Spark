# Uniform DGX Spark

面向 NVIDIA DGX Spark 的本地 vLLM 模型部署与可视化管理平台。

项目采用严格的阶段验收流程：每个阶段完成实现与测试后停止，只有在用户明确验收通过后才进入下一阶段。

当前状态：阶段 0～40 已实现，阶段 41 开发侧验收完成，待用户人工确认。模型中心统一提供“一键部署”：首次部署由 Codex/Claude Code/DeepSeek Harness
结合模型与本机环境选择推理引擎、镜像和参数，完成权重下载、容器启动、健康检查和真实推理
测试；验证成功后平台会保存脱敏部署参考及绑定容器身份的启动/停止脚本，并通过一次停止、
启动、健康检查和真实推理后启用直接复用。同一模型再次部署时优先复用仍在运行的服务、已认证
生命周期脚本或结构化 vLLM 参数；脚本失败及复杂多机任务优先交回原 AI 会话，必要时再由带
持久化备份上下文的新会话接管。
“本地模型”页面支持添加多个绝对目录，只读扫描模型架构、量化格式、权重完整性和空间占用。
AI 会话支持自主部署、交互审批和明确授权的完整宿主机权限三种执行模式。
每次 AI 部署使用统一结果契约，页面集中展示容器、镜像、端口、启动命令、健康检查和推理测试。
系统监控可登记 SSH 节点，动态展示双机的实际 IP、CX-7/RDMA 接口、链路速率和运行容器。
RDMA 状态区分物理链路、IP 配置和对端可达性，不把 200 Gb/s 物理协商误报为网络可用。
模型目录汇总 Hugging Face 与 ModelScope 数据并自动去重，优先展示 Hugging Face 条目，支持
按近期热度、发布时间、下载量、点赞数和名称排序。卡片只呈现模型信息与发布组织头像，不显示
跨站合并细节，并展示实际权重下载大小、仓库总量、量化/精度、模型结构和参数量等基础信息。
部署后的服务可执行可视化并发性能测试，配置输入/输出长度、并发和请求数，持久化吞吐、延迟
分位数与成功率；汇总结果可以交给 AI 分析，但测试 Prompt 和响应正文不会保存。
模型精度评测保留手动配置，并提供“AI 一键评测”：Codex 根据自然语言需求提交方案，用户确认后
平台通过固定 EvalScope 先试跑再正式评测，展示标准指标与独立 AI 解读。AI 使用专用会话工具，
不能自行部署/重启模型或写入分数。使用与验收见 [AI 精度评测助手](docs/acceptance/ai-accuracy-assistant.md)。
独立的 Spark Arena 评测页使用 `llama-benchy 0.4.0`，提供官方口径预设、实时进度与日志、
原始 JSON 下载，并可选择 Spark Arena 榜单条目计算 Prefill、Decode 和 TTFR 差距。
性能评测与 AI 会话使用两个独立顶层页面。性能页将 Arena 对标与自定义测试作为平级入口并
集中展示结构化结果；原始 CLI 过程和人工干预只在 AI 会话页呈现。自定义测试由 AI 结合实时
部署、容器与硬件上下文，从项目内置的 Atlas、SGLang 和 vLLM 参考代码中选择并调整方案。
停止的 AI 会话可从原上下文继续，服务日志提供实时推送和轮询回退。
运行中的托管或 AI 部署服务可以显式发布到局域网，并从同一发布继续开启 Cloudflare Quick
Tunnel 外网访问。平台生成独立 Base URL 与一次性 API Key，通过默认 `18181` 端口的受限网关
代理 OpenAI 兼容推理接口；外网入口复用同一路径和 Key，但使用 HTTPS，且不会暴露模型原始
端口。发布支持密钥轮换、独立关闭外网入口以及随时撤销全部访问。
页面右下角提供可视化 UI 编辑模式：启用后右键选中任意界面元素并输入修改批注，平台会让
Codex 在隔离副本中修改前端源码，完成语法与并发冲突检查后自动应用和刷新，并支持安全撤销。

启动本地平台：

```bash
./scripts/run-local.sh
```

浏览器打开 `http://127.0.0.1:18180`。

完整验收：

```bash
./scripts/accept-all.sh
```

使用方法见 [用户指南](docs/USER_GUIDE.md)，系统设计见 [架构说明](docs/ARCHITECTURE.md)，
外部 AI 工具接入见 [DeepSeek Harness 插件](docs/HARNESS_PLUGIN.md)，各阶段的测试方法位于 `docs/acceptance/`。

外部 AI 工具插件可直接打包分发：

```bash
python3 scripts/build-dsh-plugin.py --out dist
```

DeepSeek Harness 使用生成的 `.tgz` 组合包；`.zip` 只用于源码审阅。产物还包含标准
MCP server、配置工具和主机侧局域网/鉴权配置脚本。
